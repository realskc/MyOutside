# D-0074 用量与花费：按子应用统计，按官方价格与调用时段估算

- 状态：有效
- 日期：2026-10-27
- 决策者：agent（作者要求「搞一下」）
- 服务于：
  - 作者预期：[platform.md「平台 AI」](../platform.md)（AI 是平台提供给各子应用的核心能力）
  - 上游决策：[D-0014](0014-deepseek-as-ai-provider.md)（DeepSeek）、[D-0050](0050-web-tools-as-platform-api.md)（搜索与抓取）

## 决策

- 每次成功的平台 AI 调用、搜索、抓取，按调用者（子应用）记一条用量（此前已实现），**写入时按当时的价格估算花费**（`cost_yuan`），之后价格变动不影响历史记录；早期没有花费列的记录在启动时补算一次；
- 价格取自 DeepSeek 官方「模型 & 价格」页（2026-10-27）：模型按缓存命中输入 / 缓存未命中输入 / 输出分别计价；高峰时段（北京时间周一至周五 9:00–12:00、14:00–18:00）全价，其余时段半价；搜索、抓取各 5 元 / 千次成功请求；
- 平台 API `platform.usage.summary`（只给外壳）按调用者汇总；设置页「用量与花费」按今天 / 近 7 天 / 近 30 天 / 全部显示各子应用的 AI 调用次数、输入（其中命中缓存）、输出（其中思考）、搜索 / 抓取次数与估算花费。

## 考虑过、没有采用

- 只显示 token 与次数、不折算成钱：作者关心的是花了多少钱；
- 查询时再按价格计算：价格变动会改写历史花费。

## 代价

- 是估算：不识别法定节假日（节假日全天是空闲价，这里按工作日计，会略微高估）；被停止的回复拿不到用量，不计入；价格写死在代码里（`packages/kernel/src/pricing.ts`），DeepSeek 调价后需要手动更新；
- 记录用量之前（2026-10-26 之前）的调用没有数据。

## 什么时候应该重新考虑

- DeepSeek 调价、或者接入别的模型提供方时（更新价格表）；
- 需要按子应用设预算、限额时；
- 其余随时可以。
