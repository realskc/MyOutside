# D-0019 AI 密钥存在平台设置里（明文）

- 状态：有效（临时方案）
- 日期：2026-10-02
- 决策者：讨论
- 服务于：

## 决策

- DeepSeek API Key 存在平台设置表（`platform_setting`，SQLite 明文）；
- 平台 AI 代理读取密钥并代为调用，子应用不直接接触。

## 代价

- 明文存储；
- 当前任何子应用都能通过 `platform.settings.get` 读到密钥（见 D-0006「代价」）——与用户预期不符，已知，暂不处理。

## 什么时候应该重新考虑

- 迁移到系统钥匙串（已计划）；
- 平台设置的访问权限需要按调用者区分时。
