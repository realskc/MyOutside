# D-0060 工具循环在模型不调用工具时结束

- 状态：有效（暂时）
- 日期：2026-10-24
- 决策者：作者
- 服务于：
  - 作者预期：[platform.md「平台 AI」](../platform.md)（agent 框架必须共享）
  - 上游决策：[D-0059](0059-no-tool-choice.md)

## 决策

共享库中的工具循环只有一种结束方式：模型的某一次回复不再调用工具，循环结束，这次回复即为结果——与主流 agent 一致。

## 考虑过、暂不采用

- **「结束工具」**：工作流指定某些工具，模型调用它们时循环也结束，并以工具参数作为结构化结果。
- **只有显式结束**：只有调用结束工具才算结束；纯文字输出当作中间消息显示给用户，循环继续。
- 用 `tool_choice: required` 强制每一步调用工具：思考模式下不支持（D-0059）。

## 理由

先与主流一致、最稳。作者还在思考更通用的结束形式。

## 什么时候应该重新考虑

很可能会变：等子应用多了、作者想明白了更通用的结束形式之后。
