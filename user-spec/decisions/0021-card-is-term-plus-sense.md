# D-0021 卡片数据模型：一张卡片 = 单词 + 本质意项，没有独立的「单词」层级

- 状态：有效
- 日期：2026-10-01
- 决策者：讨论
- 服务于：
  - 用户预期：[apps/vocab.md「卡片」](../apps/vocab.md)（同一个单词的两个本质不同的释义，就是两个不同的单词）

## 决策

- 表 `card` 每行一张卡片：`term`（归一化拼写：trim + 小写 + 折叠空格，只用于机械查重）、`display`（原始写法）、`sense`（本质意项，人话描述）、`phonetic`（音标）、`meaning`（释义）、`context` / `source`（语境与来源，为跨应用抓词预留）、`status`（学习中 / 已掌握）、FSRS 调度字段；
- 没有「单词」表；同一拼写的卡片只是恰好共享 `term`，统计与展示都按卡片；
- 音标按卡片记（read、lead 这类同词不同音由卡片承载）；
- 复习日志（revlog）不落库；词形归并（running → run）暂不做。

## 什么时候应该重新考虑

字段与存储方式随时可以调整，只要仍满足「本质不同的释义是不同的单词」。
