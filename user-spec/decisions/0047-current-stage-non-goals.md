# D-0047 现阶段不做的事

- 状态：有效
- 日期：2026-10-01
- 决策者：讨论
- 服务于：
  - 作者预期：[product.md「用户与阶段」](../product.md)（阶段 0 只有作者一人使用；先推进实用的功能和 demo）

## 决策

阶段 0 明确不做：

- 第三方开发者生态、权限沙箱、协议兼容性承诺（子应用全部由作者本人开发）；
- 实时协同、面向多端的推送；
- 多实例、多用户、跨设备同步；
- 完整的撤销、审计、时间旅行（保留将来引入软删除或事件日志的余地）。

## 代价

- 「权限沙箱」与 `principles.md`「硬约束是用户自由享受 vibe coding 的保底」存在张力：当前的硬约束只覆盖数据归属（D-0005），没有覆盖调用权限（见 D-0006「代价」）。
- 没有撤销：误删或改坏的数据无法恢复（`platform.md`「未定」：数据恢复很重要，以后要思考）。

## 什么时候应该重新考虑

- 进入阶段 1（分发给朋友）时，逐条重新评估，尤其是权限沙箱与数据恢复；
- builder 或临时函数开始修改真实数据时（数据恢复）。
