# D-0013 多端方案：云端内核

- 状态：有效（方向已定；实施在双端需求出现时启动）
- 日期：2026-10-01
- 决策者：讨论
- 服务于：
  - 作者预期：[platform.md「多端」](../platform.md)（个人数据在电脑与手机之间共用）

## 决策

- 内核与子应用后端运行在云端（作者自租服务器），外壳与子应用前端在每台设备本地；设备端 = 外壳 + 前端 + SDK（经网络传输）；
- 离线 / 本地缓存后置，且按子应用定制。

## 考虑过、没有采用

| 方案 | 没有采用的原因 |
|---|---|
| 本地优先（每台设备一个内核 + 同步层） | 需要冲突合并，复杂度高 |
| 云端内核 + 本地只读缓存 | 不是不用，而是后置；缓存高度按应用定制 |
| 家里的设备当内核 | 依赖隧道与设备常开 |

防线保留：坚持「所有写入都经过内核」，将来若要本地优先，可在内核层增加变更捕获，不动子应用代码。

## 代价

- 需要身份 / 登录（哪怕单用户）、TLS、服务器运维；
- 离线时不可用（直到补上缓存）。

## 什么时候应该重新考虑

- 离线使用成为强需求；
- 不想维护服务器。
