# D-0042 哲野的配方以人可读文件随仓库版本化

- 状态：有效（未实现）
- 日期：2026-10-07
- 决策者：用户（认真思考后敲定）
- 服务于：
  - 上游决策：[D-0041](0041-zheye-no-profiling.md)（配方迭代在开发环中进行）

## 决策

- 模板、质量标准、各阶段提示词合称**配方**，以人可读文件（Markdown / TS 常量）随仓库版本化，由人与 Agent 快速迭代；
- 每篇文章记录所用的配方版本，保证可追溯；
- 计划提供试验脚本（如 `scripts/zheye-trial.ts`），在终端里喂一段文本、看各阶段产物，快速迭代配方；
- 将来配方可以搬进数据库，由 builder 用自然语言编辑。
