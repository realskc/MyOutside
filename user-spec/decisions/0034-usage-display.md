## 决策

- 平台 AI 透传 token 用量（输入 / 输出 / 思考 / 合计），助手消息落库保存；
- 每条助手回复的操作栏显示本条明细（悬停可见）；
- 输入区右侧显示**本会话累计**用量（汇总所有分叉）。

## 代价

- 作者真正需要的是「当前上下文长度」，而当前最醒目的数字是**累计用量**，两者不是一回事；当前上下文长度只能从最近一条回复的输入 token 间接看出。

## 什么时候应该重新考虑

随时可以——建议直接显示当前上下文长度。
