# D-0077 子应用可以请外壳用系统默认程序打开自己目录下的文本文件

- 状态：有效
- 日期：2026-10-28
- 决策者：agent
- 服务于：
  - 第一个使用者：[ZHEYE-0020](../../apps/zheye/user-spec/decisions/ZHEYE-0020-trial-bench.md)（试验台上的「在编辑器里打开」提示词文件）

## 决策

- 预加载桥加一个 `outside.openAppFile(path)`：Electron 主进程用 `shell.openPath` 以系统默认程序打开文件；
- 只能打开**发起调用的子应用自己目录**（`apps/<id>/`）下、已经存在的 `.md` / `.json` / `.txt` 文件；调用者按 IPC 的页面地址确定（同 D-0070），外壳不能用；
- 不经过内核：打开文件是外壳的能力，不是数据 API；局域网预览（D-0072）没有这个能力，页面要自己处理「打不开」。

## 理由

作者要在编辑器里改提示词，试验台上一键打开最顺手；把范围限定在本应用目录与几种文本类型，避免子应用借它打开可执行文件或别的应用的文件。

## 什么时候应该重新考虑

- 打包发布、子应用目录不再是仓库目录时；
- 出现需要打开其他类型文件的子应用时。
