# D-0041 哲野不做口味档案、不做应用内反馈；不要求对原文高保真

- 状态：有效
- 日期：2026-10-07
- 决策者：作者（认真思考后敲定）
- 服务于：
  - 作者预期：[apps/zheye.md「愉悦」](../apps/zheye.md)（不投其所好、不做画像）
  - 作者预期：[apps/zheye.md「读者」](../apps/zheye.md)（固定的读者形象）
  - 作者预期：[apps/zheye.md「真实性」](../apps/zheye.md)

## 决策

- **不做口味档案**：难以沉淀，而且偏离「学到真东西」的目标；
- **应用内不做反馈系统与任何画像**；配方迭代在开发环中进行（人 + Agent，见 D-0042）；
- **不对原文施加「高保真」约束**：文章是精读成果，允许重构、综合、补背景；但必须真实。
