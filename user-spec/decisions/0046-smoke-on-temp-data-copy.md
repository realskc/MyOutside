# D-0046 冒烟测试在真实数据的临时副本上运行

- 状态：有效
- 日期：2026-10-07
- 决策者：agent
- 服务于：
  - 作者预期：[workflow.md「不能破坏作者的生活数据」](../workflow.md)

## 决策

`pnpm smoke` 启动时把真实数据库复制到系统临时目录，在副本上自检、做演示写入并截图，然后自动退出；真实数据不受影响。

- 使用独立的临时 Electron 配置目录：不和正在运行的 MyOutside 抢单实例锁，可以同时运行；
- 默认在后台运行：窗口不显示、不抢焦点、不在 Dock 出现（窗口不可见时照常渲染，截图不受影响）；调试时用 `MYOUTSIDE_SMOKE_SHOW=1` 显示窗口。

## 理由

既能用接近真实的数据验证界面，又不污染真实数据。作者没有「一定要用假数据」的要求。后台运行是作者提出的：跑测试时 Electron 不要弹到面前。

## 什么时候应该重新考虑

随时可以，只要仍不破坏真实数据。
