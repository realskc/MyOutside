# D-0016 单实例运行；Windows 双击快捷方式、macOS 终端命令启动

- 状态：有效
- 日期：2026-10-02
- 决策者：agent
- 服务于：—

## 决策

- 应用带单实例锁：重复启动时聚焦已有窗口；
- Windows 上提供桌面快捷方式（`scripts/launch/`），静默启动、不弹控制台；
- macOS / Linux 上提供终端命令 `myoutside`（`scripts/launch/myoutside`，链接到 `~/.local/bin`）：在任意目录启动，后台运行、终端立即可用；已在运行时不重新构建，直接聚焦已有窗口。

## 理由

单实例与「内核是唯一写入者」（D-0004）一致，避免两个进程同时写同一个数据库。快捷方式是开发期的便利。

## 代价

- macOS 上没有可双击的图标，要在终端输入命令；需要手动建一次 `~/.local/bin` 的链接。

## 什么时候应该重新考虑

- 启动方式：随时可以（作者不了解也不关心这件事）；
- 单实例：只要仍满足「同一份数据只有一个写入者」，随时可以。
