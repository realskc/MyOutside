# D-0039 哲野的三类文章模板（「讲透」的操作化定义）

- 状态：有效（未实现）
- 日期：2026-10-07
- 决策者：用户（认真思考后敲定）
- 服务于：
  - 用户预期：[apps/zheye.md「目的」](../apps/zheye.md)（把被讲的点讲好、讲透）

## 决策

**词（concept）**

1. 它为了解决什么问题而存在
2. 一句人话定义
3. 直觉与最小例子
4. 怎么运作（机制）
5. 边界与常见误解
6. 与相邻概念的关系

**句（statement）**

1. 这句话在断言什么（拆开主语、量词、条件）
2. 为什么它不是显然的
3. 证据与机制
4. 适用范围与反例
5. 若成立意味着什么（推论 / 意义）

**文（doc）**

1. 它想解决什么问题
2. 主要贡献（2–3 条）
3. 论证路径（方法如何走到结论）
4. 在领域中的位置（为什么值得知道）
5. 局限与未决
6. 想深入原文时看哪几节
