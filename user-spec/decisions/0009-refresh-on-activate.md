# D-0009 不做实时推送：面板激活时比对数据版本再刷新

- 状态：有效（「不推送」部分被 [D-0051](0051-event-centric-agent-runs.md) 取代：推送用于运行进度；数据刷新模型不变）
- 日期：2026-09-30
- 决策者：讨论
- 服务于：
  - 上游决策：[D-0010](0010-single-window-single-active-panel.md)（同一时刻只有一个活动面板）

## 决策

- 内核不向界面推送数据变化；
- 子应用面板被打开或切换回来时，比对全局数据版本号（DataVersion），变化了就重新查询。

## 理由

单活动面板下，用户看不到后台面板，激活时刷新已经足够；推送需要额外的通道与订阅机制。

## 什么时候应该重新考虑

随时可以——这只是「目前不需要，所以没做」，不是作者的要求。可以预见的触发点：

- 需要显示长时间操作的进度（例如 agent 执行搜索、多步工具调用）；
- 同屏显示多个面板。

可选增强：提交后只给当前活动面板发一条轻量通知；协议形状不变。
