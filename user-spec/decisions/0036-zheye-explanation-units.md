# D-0036 哲野的讲解单元：词 / 句 / 文三种，三种来源

## 决策

- 讲解单元是应用的中心对象，「单元 → 文章」一对一；
- 三种单元：
  - **词**（concept）：某个概念；
  - **句**（statement）：性质、结论、insight、现象、原型；
  - **文**（doc）：某篇源材料；
- 三种来源：用户直接提出；从源材料提取候选点（用户挑选）；前置递归展开（自动创建，见 D-0037）。
