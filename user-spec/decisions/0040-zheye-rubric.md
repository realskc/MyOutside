# D-0040 哲野的质量标准（rubric）

- 状态：有效（未实现）
- 日期：2026-10-07
- 决策者：可能是 agent（用户不记得具体内容是谁定的）
- 服务于：
  - 用户预期：[apps/zheye.md「目的」](../apps/zheye.md)、[「真实性」](../apps/zheye.md)

## 决策

生成后逐条检查（写作与检查共用同一份标准）：

- 核心论点、关键推理、重要前提一个不丢
- 难点必须被解开，不允许跳过难的部分——这是「精读」与「摘要」的分界线
- 术语能不用就不用；出现即用白话解释
- 数学 / 形式化：先给直觉，再按需给细节
- 结构 = 论证骨架；每一步都知道在论证什么
- 开头直接给出「这篇在解决什么问题 / 你能获得什么」（为了定位，不是为了抓眼球）
- 真实性：不编造、推测不当定论（硬约束，来自用户预期）
- takeaway 测试：读完能用自己的话复述
- 无注水；长度服从内容

## 什么时候应该重新考虑

随时可以——除「真实性」一条来自用户预期外，其余条目都可以在配方迭代中调整（见 D-0042）。
