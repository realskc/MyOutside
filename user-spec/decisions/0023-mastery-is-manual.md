# D-0023 「已掌握」完全由用户手动标记

- 状态：有效
- 日期：2026-10-01
- 决策者：作者
- 服务于：
  - 作者预期：[apps/vocab.md「定位」](../apps/vocab.md)（维护「我的英语状态」）

## 决策

复习间隔会持续增长，但卡片的「已掌握」状态只由用户显式标记（复习页的「完全学会」、词库页的「标记已掌握」），不会因间隔足够长而自动变成已掌握。已掌握的卡片移出复习队列。

## 理由

作者还没想好自动判定的阈值，想先用手动标记试一下；没有其他特别的原因。

## 什么时候应该重新考虑

随时可以——例如设置一个自动判定的阈值。
