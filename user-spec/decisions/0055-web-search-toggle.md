# D-0055 对话的「联网搜索」开关：默认打开，打开时由模型决定搜不搜

- 状态：有效（未实现）
- 日期：2026-10-21
- 决策者：讨论（作者同意）
- 服务于：
  - 作者预期：[apps/dialog.md「定位」](../apps/dialog.md)

## 决策

- 每个会话一个「联网搜索」开关，默认打开；
- 打开：本轮回复把搜索、抓取工具交给模型，由模型判断要不要用；
- 关闭：不给这些工具，模型无法联网。

## 理由

兼顾自然（问时事时模型自己会去搜）与可控（想省钱或不想被打扰时可以关掉）。搜索本身 5 元 / 千次，几乎可以忽略；主要费用是搜索结果占用的上下文 token。

## 什么时候应该重新考虑

随时可以。
