# D-0003 全项目单一语言：TypeScript

- 状态：有效
- 日期：2026-09-30
- 决策者：讨论
- 服务于：
  - 用户预期：[platform.md「技术选型的总体预期」](../platform.md)（优先考虑 Agent 的可迭代性）

## 背景

开发以 Agent 为主。语言越多，Agent 需要同时掌握的上下文、构建链与调试手段越多，反馈环越慢。

## 决策

宿主、内核、契约、子应用后台与界面统一使用 TypeScript（子应用界面目前仍是纯 JS，见 D-0011，计划改为 TS）。契约（类型 + zod 校验）放在 `packages/contracts`，作为单一事实来源。

## 考虑过、没有采用

- 宿主用 Rust（Tauri）+ 子应用 TS：两种语言，内核与子应用后台无法同进程同语言。

## 什么时候应该重新考虑

- 出现 TypeScript 生态无法满足、且必须由其他语言承担的核心能力。
