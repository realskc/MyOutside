## 决策

- 左栏会话列表、右栏消息流 + 输入区；窄屏时列表收为抽屉；
- Markdown 极简渲染（零依赖、转义优先），代码块带复制按钮，无语法高亮；
- 回复中的链接可点击（仅 http/https），用系统浏览器打开；
- Enter 发送、Shift+Enter 换行，处理中文输入法组字；
- 每会话可自定义系统提示词；标题取首条用户消息（约 24 字），可手动重命名；
- 生成中可以切到其他会话。
