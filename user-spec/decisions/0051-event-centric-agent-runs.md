# D-0051 agent 运行以事件为中心；流式输出与进度显示共用推送通道

- 状态：有效（未实现）
- 日期：2026-10-21
- 决策者：agent
- 服务于：
  - 用户预期：[apps/dialog.md「定位」](../apps/dialog.md)（能作为主力对话工具）
  - 上游决策：[D-0049](0049-agent-layering.md)

## 决策

- 一次 agent 运行产生一串事件（开始一步、模型输出、开始调用工具、工具结果、结束；以后加文字 / 思考增量）；
- 内核新增推送通道：执行中经 `ctx.emit` 把事件推回发起调用的界面；调用的最终结果仍按请求-响应返回；
- 没有推送通道时 emit 为空操作，运行不受影响。

## 理由

流式输出与「正在搜索 xxx」这类进度，本质都是「后端执行中往界面推东西」；一开始就按事件设计，以后加逐字流式时接口不用变。

## 影响

推翻 D-0009 中「不推送」的部分：推送用于运行进度；数据刷新模型不变。

## 什么时候应该重新考虑

随时可以。
