# D-0097 服务器试用阶段：大家共用作者的 key（存在平台库），朋友每周 ¥20（发请求前检查），邀请链接注册

- 状态：有效
- 日期：2026-11-14
- 决策者：agent（共用作者的 key、每周 ¥20、邀请制是作者定的）
- 服务于：
  - 作者预期：[product.md「用户与阶段」](../product.md)（试用阶段）、[platform.md「分发与隔离」](../platform.md)（邀请制，只能用作者的子应用，数据库独立）、[platform.md「平台 AI」](../platform.md)（试用阶段用作者的 key；用量管控：每个朋友每周最多 ¥20）
  - 上游决策：[D-0091](0091-one-database-per-user.md)（每个用户一个库）、[D-0093](0093-login-and-server-hardening.md)（登录与安全；取代它「密钥」一条在试用阶段的做法）、[D-0074](0074-usage-and-cost-display.md)（用量与花费估算）

## 背景

作者要先在服务器上做一个试用阶段：邀请朋友来用作者的子应用，AI 用作者的 key，每个朋友每周最多花 ¥20，超了提示额度用完。原来的做法是每个用户的 key 加密存在他自己的库里（D-0093），作者在服务器上用命令建账号、发设置链接。

## 决策

**共用的 key 只有一把，存在平台库里**：`platform.db` 的 `server_setting` 表，用服务器的主密钥加密（和原来存用户 key 的方式一样，D-0093）。管理员在设置里原来填 API key 的地方填它（显示为「大家共用」）；其他用户的设置里没有这一栏，换成「AI 额度」：本周已用多少、上限多少、什么时候恢复。谁都读不到 key 的值，子应用照旧拿不到（platform.md「平台 AI」）。

- 内核加了一个可选项 `credentials`：凭据从哪读、往哪写由运行环境决定。服务器给每个用户的内核都指向这把共用的 key；只有管理员的内核能改它，其他人改会得到 `FORBIDDEN`。Electron 不传，照旧存在本机的库里。

**额度在发请求之前检查**：内核加了一个可选项 `quota`。服务器只给不是管理员的用户的内核加：每周 ¥20，从北京时间周一 0 点算起，到下周一 0 点。每次发 AI、搜索、抓取请求之前，算这个用户自己库里本周记下的估算花费（D-0074）；到了上限就不发，报 `QUOTA_EXCEEDED`：「本周的 AI 额度（¥20）用完了，下周一 0 点（北京时间）恢复」。作者自己不限。

- 按用户算总数，不分子应用：作者说的是「每个朋友每周」。按子应用的花费照旧在用量表里显示。
- 用自然周而不是「最近 7 天」：和「每周」的说法一致，朋友也好理解什么时候恢复。

**邀请链接注册**：管理员在设置里点「生成邀请链接」（服务器上也可以用 `myoutside-admin invite`）。链接里是随机长令牌，平台库只存它的哈希；7 天过期，用一次就作废。朋友打开后自己起用户名、设密码，注册完直接登录，不是管理员。用户名被占时报错，链接不算用掉。用过的邀请记录留着（谁邀请了谁），过期没用的定期清掉。

- 这是没登录时能碰的又一个入口，和一次性设置链接同一类（D-0093）：要来自自己的页面，Caddy 先挡掉超过 4 KB 的请求，先确认链接有效再算密码哈希。

**管理员能看到每个用户花了多少**：设置里的「用户」表列出每个人本周和一共的估算花费，以及额度。朋友用的是作者的钱，作者要看得到。

**进入试用阶段时重新评估 D-0047（现阶段不做的事）**：

- 权限沙箱（后端关进沙箱）：试用阶段服务器上只有作者写的子应用，先不做；用户自己写的子应用上服务器之前必须做（platform.md「分发与隔离」）。
- 多用户：D-0091 已经做了。
- 数据恢复：服务器整个没了、或者数据被改坏，可以从每天的备份退回（D-0092、D-0096）；只退回某一个用户的库要手动做。

## 考虑过、没有采用

- **共用的 key 存在作者自己的库里，别人的内核去读**：要跨用户读库，还把服务器的配置和作者个人的数据混在一起。
- **朋友各自填自己的 key**：作者定了试用阶段用作者的。
- **每次请求前先「预扣」一笔**：请求结束前不知道要花多少；不预扣时最多略超一点，¥20 的额度下可以接受。
- **朋友也能发邀请**：现在只有作者需要邀请人；朋友要邀请时再说。

## 代价

- 花费是请求结束后才记上的：同时进行的几个请求可能一起略超上限；估算按官方价格算，不识别节假日的空闲价，和 DeepSeek 的账单会有出入（D-0074）。
- 试用阶段朋友不能用自己的 key。
- 一个用户的内核打开时就定了他是不是管理员；改了管理员身份，要等他的内核闲置关掉（30 分钟）或重启服务才生效。

## 什么时候应该重新考虑

- 进入正式阶段（每个用户用自己的 key，platform.md「平台 AI」）；
- 朋友经常卡在额度上，或者作者觉得花得太多；
- 需要按子应用分别限额时；
- 管理员不止作者一个时。
