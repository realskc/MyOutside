# D-0029 对话消息树：父指针 + 当前选中的分叉指针

- 状态：有效
- 日期：2026-10-07
- 决策者：讨论
- 服务于：
  - 作者预期：[apps/dialog.md「对话历史」](../apps/dialog.md)（树形历史；所有消息永久保留）

## 决策

- 每条消息记录 `parent_id`，构成消息树；
- `conversation.active_first_id` 与每条消息的 `active_child_id` 记录「当前选中的分叉」，从根沿选中的子消息下降得到**当前路径**；界面渲染与发给 AI 的上下文都取当前路径；
- 切换分叉只改指针，旧分支数据不丢，切回时原样恢复（含各层此前的选择）；
- 删除只有「删除整个会话」一个入口，不支持删除单条消息。

## 什么时候应该重新考虑

存储方式随时可以调整，只要仍满足树形历史与永久保留。
