# 统一能力

> 状态：构想（2026-11-05），尚未设计和实现。
> MyOutside 是富有智能的数字家园（见 [vision.md「数字家园」](../vision.md)）。作者计划将来给它加入更多的「统一能力」。

## 1. 入口统一

有一个统一的对话入口（提供路由能力）：用户的各种需求都可以在同一个地方用自然语言发出，再路由到不同的子应用。

## 2. 事件记录统一

用户在 MyOutside 所有子应用中的行为都被统一地记录下来，它们构成用户的生活记录（的一部分）。

## 3. 界面能力统一

让 MyOutside 像一个 GUI 操作系统：不同的子应用可以在不同的窗口里自由地布局和摆放，产生很好的整体显示效果。

## 4. 记忆数据统一

子应用需要记住的、和用户相关的东西（例如用户的特点、用户的经历、用户已有的知识），由一处统一的能力承载，提供语义检索或更智能的能力。

## 未定

- 各项的具体形态、先后顺序和实现时机都还没有展开。
