# 平台结构

这一组是**逻辑概念**：回答「它是什么、负责什么」，不随部署方式改变（现在全部在一个 Electron 程序里；将来多端时会分散到云端与各设备上，含义不变）。

关系：**平台**包含**内核**与**外壳**；MyOutside = 平台 + 所有子应用。

## 平台

- 定义：MyOutside 中**不属于任何子应用的部分**的总称，包括内核、平台提供给子应用的服务（平台 AI、平台设置等）、外壳。
- 例子：平台设置、平台 AI、设置页都属于平台；学英语的卡片、对话的消息不属于平台。
- 例子：DeepSeek API Key 是**平台的数据**——它存在平台设置里，不属于任何子应用；子应用通过平台 AI 使用它，自始至终看不到它。
- 不是内核：平台说的是「归谁」（不属于任何子应用的那部分），内核说的是「怎么运转」。目前二者的代码在同一个包里，但它们是本质不同的东西。

## 内核

- 定义：平台中负责**运转机制**的部分：调用怎么路由、参数怎么校验、写操作怎么排队进事务、迁移怎么执行；将来还有权限检查与推送。
- 例子：「两个写操作不会同时执行」「跨应用加词要么都成功、要么都失败」，都是内核保证的。
- 例子：在设置页保存 DeepSeek API Key 时，是内核把这次写入放进写队列、在事务里写进数据库——Key 归平台，存取由内核负责。
- **内核是唯一写入者**：所有数据写入都经过内核。

## 外壳

- 定义：平台的**界面**：子应用列表、设置页；将来「像手机桌面的主页」也属于外壳。
- 例子：你填 DeepSeek API Key 的设置页；窗口左侧的子应用列表。
- 不是子应用的界面：打开对话时，右侧的聊天界面是对话子应用的界面，不是外壳。
- 多端以后，每台设备上各有一份外壳。

## 不作为概念的词

- **宿主**：它说的是「跑在哪个程序里」，属于部署层面，会随部署方式改变含义，所以不作为概念。现阶段需要指这个程序时，直接说 **Electron**（程序）。将来多端时再整理部署层面的用词（例如服务端 / 客户端）。
