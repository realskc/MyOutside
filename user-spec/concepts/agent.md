# agent

层次（从大到小）：子应用 → 工作流 → LLM 步骤 → LLM API 的单次调用。

## 工作流

- 定义：一套包含 LLM 调用与工具的程序流程。**agent 就是工作流。**
- 工作流用代码实现，以库函数或平台 API 作为能力组件（见 `../platform.md`「平台 AI」）。
- 例子：学英语添加卡片时的判重——先查有没有同一拼写的卡片；没有就直接判定为新卡片；有的话调用一次模型，问它新卡片是否与已有卡片同义；再根据结果给用户展示选项。
- 例子：对话的生成回复——取出当前对话路径，截断到上下文预算之内，调用模型得到回答。
- 不是：整个子应用。对话应用里只有「生成回复」是工作流；切换分支、重命名等是普通的数据操作。

## LLM 步骤

- 定义：工作流中**调用 LLM 的那一步**：有明确的开始与结束，几秒到几分钟内完成。
- 形式举例：
  - 单次调用：问一次模型，拿到回答。例：对话现在的生成回复（不带工具）。
  - 结构化调用：问一次模型，要求它按指定格式给出结果。例：学英语判重——模型给出「与第几张已有卡片同义」。
  - 工具循环：见下。例：对话加上搜索后的生成回复。
- 共享库具体以什么形式提供这些能力属于细节，见 `../platform.md`「平台 AI」。

## 工具循环

- 定义：一种 LLM 步骤：反复让模型决定下一步——调用模型；如果模型调用了工具，就执行工具、把结果交回模型，再调用模型；如此反复，直到模型的某一次回复**不再调用工具**，循环结束，这次回复就是结果。
- **轮**：工具循环内部的每一次「调用模型（并执行它要求的工具）」叫一轮。
- 例子：对话加上搜索后——第一轮模型调用搜索工具；第二轮看了搜索结果后调用抓取工具读一个网页；第三轮不再调用工具、直接给出回答。
- 结束条件：模型不调用工具即结束（与主流 agent 一致）。这是暂时的决策，见 [D-0060](../decisions/0060-tool-loop-ends-without-tool-calls.md)。
- 与工作流的关系：一个工作流可以包含零个、一个或多个工具循环。学英语判重的工作流里没有工具循环（只调用一次模型）；对话加上搜索后，生成回复的工作流里包含一个工具循环。
