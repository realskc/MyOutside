# 概念

这个目录给 MyOutside 里的东西起**明确的名字**：

- 作者与 agent 工作时，能区分概念、把事情说清楚——对思考和讲解都有帮助，尤其是向作者讲解时，可以借助概念把具体的例子讲清楚；
- 作者与 agent 之间对齐：抽象概念有统一的命名非常重要。

其他文档（spec 文档、决策、技术文档）使用这里的名字；一个概念只用一个名字。

## 规则

- 概念的讨论必须慎重，一点一点确定；
- **概念条目的改变必须由作者提出**；agent 可以做一些修改调整（例如补例子、修措辞，不改变含义）；
- concepts 属于 user spec：修改后同样要在回答末尾用 🟢 向作者汇报。
