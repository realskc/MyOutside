# 愿景与哲学

这里记录作者关于 MyOutside（地球online）的宏观想法：愿景、哲学、世界观。它们往往离实现还很远，有的可能永远不会直接变成某个功能。

## 怎么读

- 这里的内容是作者的想法，和 spec 文档一样，只有作者能改变它的含义。
- 但它**不是需求**：本身不产生要做的事，也不要求现在的设计去满足它。
- 它的用处：
  - **给方向**：设计时有几种做法都满足需求，可以参考这里，选更接近的那种；
  - **解释动机**：帮助理解作者为什么在意某些具体的预期。
- 某个想法想清楚、要落地时，把具体的预期写进对应的 spec 文档（`product.md`、`platform.md`、各子应用的 spec……），并链接回这里。

## 怎么记

- 作者随时可以在对话里说，agent 负责记下来。
- 尽量保留作者的原意和措辞，不改写成干巴巴的条目；没想清楚的部分照实记成没想清楚，agent 不替作者补全。
- 按主题组织，不按时间；同一主题后来有了新想法，就合并进去，必要时注明前后的变化。
- agent 自己的理解、和现有设计的联系，与作者的想法分开写，以「agent 注：」开头。
- 发现和现有的 spec 或决策冲突时，不自行调和，告诉作者。
- 只关于某个子应用的愿景，写进那个子应用的 spec。

## 想法

### 数字家园（2026-11-05）

MyOutside 的另一个定位：某种意义上的「数字家园」。

- 家，是一个基于人类自由空间和自由时间的地方。人可以在家里消费时间和空间，感受到独属于人类的乐趣。
- 世界上已经有一些具备「数字家园」能力的东西，例如个人电脑（personal computer），但还不够，我们需要引入智能。
- MyOutside 的定位就是某种**富有智能的数字家园**：人类可以把它当成家来使用。
- 作者计划将来给 MyOutside 加入更多的「统一能力」：入口、事件记录、界面能力、记忆数据（见 [future/unified-capabilities.md](future/unified-capabilities.md)）。

### 智能像灵气（2026-11-05）

- 智能（特指现阶段 LLM 提供的能力），在作者看来像某种液体或气体的独特化学物质：它不是像人类一样的个体或独立物件，反倒像玄幻小说里的「灵气」，是可以倾倒的。
- 任何东西都可以沾上一点智能。智能可以彻底改变过去几十年纯代码驱动的数字世界的建设，让所有的软件、所有的代码都沾上智能。

### 待在家里与去外面（2026-11-05）

- 「待在家里」和「帮助你在外面混」是两个需求，作者认为它们最好分离。（这层对照是 agent 在聊天中指出的：Outside 是外面的世界，家是回来的地方；地球online 的游戏面板帮你在外面玩这场游戏，数字家园是你回来的地方。作者认为有道理。）
- 作者同时有两个矛盾的想法（借《反乌托邦Pt.2》的歌词「我会八小时前行八小时做梦 八小时种朵花」来说）：
  - 希望乌托邦能同时安排你的前行、做梦和种花，也就是统一管理全部的时间和生活内容；
  - 又希望「待在家里自由消费时间」和「为某个目标而前行」是分离的：它们总归有点冲突，强行糅合会有一点矛盾。
- 这里说的分离，主要指**分离人的心理状态**：
  - 「待在家里」和「在外面前行」时，人的心理状态不同：待在家里是舒适放松的，前行则是略微紧张的。
  - 一个东西的功能会和状态产生绑定，比如人到了床上就会想睡觉。所以不应该让同一个东西让人同时处于「放松」和「紧张」两种状态。
  - 就像床用来睡觉、书桌用来学习。即使是一个家，也得有不同的房间。
- 这肯定不是现阶段的事。作者以后或许会研究一下「冒险小说」，来思考待在家里和去外面这件事。
