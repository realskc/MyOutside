# PB-0005 应用标识：id `pureblue`，中文名「纯蓝」，英文名 0x66CCFF

- 状态：有效
- 日期：2026-11-04
- 决策者：agent
- 服务于：作者预期：命名

## 背景

作者指定中文名「纯蓝」、英文名「0x66CCFF」。内核的 AppDb 表前缀要求应用 id 以字母或下划线开头（`^[A-Za-z_][A-Za-z0-9_]*$`），`0x66CCFF` 不能作为 id。

## 决策

- 应用 id：`pureblue`（表前缀 `pureblue__`）；
- 显示名：纯蓝；英文名 0x66CCFF 作为品牌副名，在界面里同时展示。

## 代价

- 应用名暂不做按语言切换；英文界面下显示「纯蓝」。
