# GO-0001 9 路围棋：提子即终局，否则只数围空、不判胜负

- 状态：有效
- 日期：2026-10-25
- 决策者：作者
- 服务于：作者临时需求：在 MyOutside 里做一个 9 路围棋子应用，飞机上和朋友联机玩。不是产品 spec 的一部分。

## 背景

作者想要一个规则特殊的围棋变体：9 路棋盘、普通围棋的落子/提子，但任何一方的棋子被提，立即终局；如果双方都提不到子，则连续两次 pass 后只显示双方围空数，不判胜负、不贴目。作者明确要求只数空（围空），不数子，这一点和 `D:\Life\project\Go`（GoZero）的 area scoring 不同。

## 决策

- 棋盘 9×9，黑先，无贴目、无让子、无手数上限。
- 一次落子只要提掉对方至少一颗子，对局立即结束：提子方胜，被提方负；不再点目。
- 如果全程没有提子，连续两次 pass 结束：只统计空点。
  - 一块空点只被黑子包围 → 全部算黑空；只被白子包围 → 全部算白空；
  - 同时被黑白包围 / 没有任何棋子包围 → 中立；
  - **棋子本身不计入任何一方**；结果显示黑空、白空、中立点。
  - 不根据目数判胜负（平台不宣布“目多者胜”）。
- 认输按钮：认输方负，对方胜。
- 自杀非法、点击无效；占点、没轮到、对局未开始/已结束的落子都拒绝，不判负。
- 因为提子即终局，打劫实际上不会发生；不需要额外的劫争规则。
- 终局归属图（只读）用半透明方块标出黑空/白空/中立，方便核对目数；不判死活。

## 考虑过、没有采用

- **照 GoZero 的 area scoring（子 + 空，中立均分）**：作者明确要求只数空、不数子；没有采用。
- **把自杀/重复局面判负**（GoZero 的 Botzone 规则）：作者要求普通围棋的自杀非法；没有采用。
- **按目数判胜负 / 贴目**：作者明确说平台不算胜负和贴目；没有采用。
- **严格死活判断（Benson / 搜索）**：与“不判死活”的预期冲突，且实现复杂；没有采用。

## 代价

- 这是“不判死活”的简化数空：一块空区只要边界只出现一种颜色就算该方，即使这块空区一直通到棋盘边缘。它不等同于严格的围棋终局死活判断，可能出现比直觉更大的目数。这是沿用 GoZero `area_ownership` 思路的结果；作者接受这个简化。
- 没有贴目/胜负判定，双方需要自己看目数决定是否继续。

## 什么时候应该重新考虑

- 作者想要更严格的围空（例如只算被棋块完整围住、排除边缘开放区域）。
- 作者想按目数判胜负或加贴目。
- 作者想支持让子、计时、贴目等正式规则。
