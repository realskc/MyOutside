# 围棋 user spec

> 这是 `apps/go` 自己的作者预期；不属于 MyOutside 平台产品 spec。它是额外的、偏临时的需求，不是正式多端方案。
>
> 技术文档见 [`../docs/README.md`](../docs/README.md)；决策见 [`decisions/`](decisions/README.md)。

## 1. 是什么

一个 9 路特殊规则围棋子应用：两个人在同一局域网/手机热点下对弈，可以聊天、请求悔棋、保存棋谱并在应用内回看。

## 2. 规则

- 9×9，黑先；无贴目、无让子。
- 落子、气、提子与普通围棋相同；额外规则：**任何一颗子被提，对局立即结束**，提子方胜、被提方负，不再点目。
- 如果全程没有提子，连续两次 pass 结束：只数空（围空），**不数子**；被双方包围/没有包围的空点算中立；平台只显示黑空、白空、中立点，**不按目数判胜负、不贴目**。
- 不判死活。
- 自杀非法；占点、没轮到、对局未开始/已结束都拒绝落子，不判负。
- 认输按钮：认输方负，对方胜。
- 提子即终局，所以打劫实际上不会发生。

## 3. 对局与联机

- 两个玩家在同一热点下联机；一个 host 只有一个对局。
- 两个玩家分别执黑/白；加入顺序、第三人观战、刷新/重启恢复等是当前实现默认，见 [GO-0002](decisions/GO-0002-go-multiplayer-and-chat.md)。
- 不需要公网、账号、房间码或正式多端同步。

## 4. 聊天、悔棋、棋谱

- 聊天：对局中有一个小聊天窗口，双方可以发消息；第三人只读。
- 悔棋：请求对方同意后，退回自己上一手及之后的应手，回到自己落子前；对方可以拒绝，请求方可以取消。终局后不能悔。
- 棋谱：保存每一盘（正常结束和中途放弃，只要有落子）；在应用内看列表并回放；**不导出 SGF/外部文件**；棋谱不记录聊天。

## 5. 界面

- 棋盘视觉可参考 `D:\Life\project\Go`（木色、线条、黑白子、最后一手、坐标、星位）；不搬它的模型/训练/复盘等部分。
- 桌面和手机都能用；手机优先保证棋盘和操作可用。

## 6. 非目标

- 不做严格死活判断、不按目数判胜负、不加贴目。
- 不做正式多端/云同步/账号体系。
- 不做 AI 对战、计时、SGF 导入导出、多桌/房间码。
- 不把围棋应用变成 MyOutside 的平台级产品 spec；它是应用自己的需求。
