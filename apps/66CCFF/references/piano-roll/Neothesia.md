# Neothesia

- 最近核对：2026-11-10
- 代码：[PolyMeilex/Neothesia](https://github.com/PolyMeilex/Neothesia)（GPL-3.0）；网站：[polymeilex.github.io/Neothesia](https://polymeilex.github.io/Neothesia/)

## 是什么

开源的 MIDI 可视化 / 学琴软件，Rust 写的，支持 Linux、Windows、macOS；目标是做开源版的 Synthesia。

## 钢琴卷帘相关的事实

- 读 MIDI 文件，把音符画成**从上往下落到虚拟钢琴上**的彩色方块（「瀑布流」），帮人学弹钢琴（README）。
- 安装包在 GitHub Releases 下载。
