# GarageBand（库乐队）

- 最近核对：2026-11-10
- 官网：[GarageBand for Mac](https://www.apple.com/mac/garageband/)；使用手册：[GarageBand for Mac User Guide](https://support.apple.com/guide/garageband/welcome-lgcpe355f8be/mac)

## 是什么

Apple 的音乐制作软件（DAW），macOS / iOS 上免费。作者的 Mac 上已装。

## 钢琴卷帘相关的事实

- 有钢琴卷帘编辑器（Piano Roll Editor）：MIDI 区域里的音符画成时间网格上的彩色长条，横向位置是开始时间、长度是时值、纵向是音高；**左边有一排琴键**作为音高参照；顶上有标出时间刻度的标尺和播放头（[Piano Roll Editor overview](https://garageband.skydocu.com/en/edit-regions/piano-roll-editor/piano-roll-editor-overview/)）。
- 卷帘编辑器在轨道区下方打开，可以上下拖动改变高度；有缩放滑块、「Catch」（播放头跟随）按钮。
- 可以编辑：⌘ 点击加音符、拖动改时间和音高、拖边缘改时值、调力度、量化、移调；点左边的琴键能选中这个音高的所有音符（[Add notes](https://garageband.skydocu.com/en/edit-regions/piano-roll-editor/add-notes/)）。
- 还有五线谱编辑器（Score Editor）。
- 打开 MIDI 文件时，每条 MIDI 轨变成一条软件乐器轨，用它自带的音色播放。
