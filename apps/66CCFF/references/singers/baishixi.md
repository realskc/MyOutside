# 白石溪

- 最近核对：2026-11-11
- 来源：[萌娘百科「白石溪」](https://moegirl.icu/%E7%99%BD%E7%9F%B3%E6%BA%AA)；网易云的歌词（LRC）

## 谁唱哪句

萌娘百科的歌词按演唱者上色：天依 `#21486a`、阿绫 `#a54253`、两人一起 `#b58915`（只有原版这样标了）。配上 LRC 每行的开始时间（行内按字数平均分时间），得到：

- 天依独唱约 64 秒，阿绫独唱约 64 秒，**两人一起约 98 秒**；
- 两人一起唱的是两段副歌（约 1:33–2:18、4:12–4:57），**基本是齐唱**（MuScriptor 的人声 MIDI 在这些地方只有 4% 的时间有两个不同的音）；
- 主歌一人一句，常常半句一换，比如「可嫌金风玉露 / 兼程久 / 灵犀心念 / 便相谋」。换得快的地方，行内按字数分时间不准；作者听出的错比按这份答案算出来的多（见 [ECAPA 想法](../separation/speechbrain-ecapa-thoughts.md)）。

这份答案只用来给对唱分轨的试验打分。歌词本身有著作权，不抄进仓库。
