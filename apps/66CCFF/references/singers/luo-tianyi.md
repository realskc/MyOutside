# 洛天依

- 最近核对：2026-11-11
- 来源：[萌娘百科「洛天依」](https://moegirl.icu/%E6%B4%9B%E5%A4%A9%E4%BE%9D)（moegirl.icu 镜像）

## 是谁

Vsinger（上海禾念信息科技有限公司，原 VOCALOID-CHINA）旗下的虚拟歌手，基于雅马哈 VOCALOID 引擎开发贩售，中文。代表色「天依蓝」**66CCFF**（纯蓝这个应用名的来历）。同团体：言和、乐正绫、乐正龙牙、徵羽摩柯、墨清弦。

## 声库版本（萌娘百科）

| 版本 | 发布 | 备注 |
|---|---|---|
| V3（VOCALOID3） | 2012-07-12 | 首个 VOCALOID 中文声库；音色 Original；声库制作人 G.K |
| V4（VOCALOID4） | 中文 2017-12-30，日文 2018-05-21 | 音色 萌（Normal）、凝（Power）；日文版声源 山新 × 鹿乃 |
| V5（VOCALOID5） | 2022-10-14 | 音色 萌、凝、婉（Nature） |
| ACE AI | 2022-08-27 公测 | ACE Studio 的 AI 声库 |
| XS AI | 2024-01-16 公测 | X Studio 的 AI 声库 |

- 声源：山新（V3、V4、V5 中文）。
- 另有 XS Talk、哔哩哔哩「鸣实验室」的说话和歌唱声库。
- 声库都是商品，要买；VOCALOID 是付费软件，ACE Studio 是订阅制（2026-11-10 和作者聊过）。

## 对纯蓝有用的推论

- **2017-12-30 之前的歌只可能是 V3**（V4 还没出）。之后的歌 V3、V4、V5、AI 都有可能，要看说明。
- 网易云上同一首歌常混着翻唱、「AI 版」「X Studio 版」「V5 翻调」，挑数据时要看清版本。
