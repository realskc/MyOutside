# 66CCFF-0002 内建慢放播放器，不依赖 Audacity

- 状态：有效
- 日期：2026-11-04
- 决策者：agent
- 服务于：
  - 作者预期：[`../README.md`](../README.md)「核心流程与预期」慢放、循环、分轨试听；「界面」不要求嵌入外部软件

## 背景

作者的现有工作流是用 Audacity 慢放听。Audacity 的脚本通道（`mod-script-pipe`）适合批量处理，但交互式循环 / AB 段不方便，且需要额外安装并启用模块。

## 决策

- 应用内建播放器：多个 `<audio>` 元素同步播放六轨；`playbackRate` 变速并保持音高；支持分轨音量 / 静音 / 独奏、循环与 AB 段；
- 不依赖 Audacity；后续可以加「用系统程序打开」（Audacity 等）作为后路。

## 考虑过、没有采用

- **自动化 Audacity**：交互体验差、需要启用模块、跨平台配置成本高。
- **嵌入 Audacity 窗口**：Windows 需要原生 hack，macOS 不可行。

## 代价

- 多音轨同步可能有毫秒级漂移；v1 用主轨时钟定期校正。
- 无波形显示（作者没有强烈需求）。

## 什么时候应该重新考虑

- 作者需要 Audacity 的频谱 / 编辑能力 → 增加「在 Audacity 打开」；
- 需要更精确的变速 / 变调 → 引入时间伸缩库或离线渲染。
