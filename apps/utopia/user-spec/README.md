# 乌托邦（Utopia）

> 这是乌托邦的作者预期。目前还在构想阶段，没有开始设计和实现。

命名：取自《反乌托邦Pt.2》（亚细亚旷世奇才 / 洛天依 / 乌托邦P）的歌词：

> 就把我迷茫带走吧
> 就把我孤单也带走吧
> 连同我的困惑我的不安统统都带走吧

（这几句后面紧接着是「至少你还在为我歌唱 / 半平米照亮了乌托邦」。）

一句话：**智能 todo list——一个执行力与规划辅助工具。**

## 定位

- 现在的 todo list 基本都是普通的，不够好。乌托邦要赋予 todo list 智能：能**拆解大任务、制定计划**等等。
- 定位更接近一个**执行力与规划辅助工具**，而不只是记下要做的事。
- 它对应 MyOutside 服务个人生活的第二个方向：借助 LLM 的高智力，提供更高层次的生活帮助——LLM 帮我拆解任务、把大任务化小、给我打气，帮助我更好地实现目标、管理生活（见 [product.md「服务个人生活：三个方向」](../../../user-spec/product.md)）。
