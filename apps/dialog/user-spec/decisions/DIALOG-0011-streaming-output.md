## 决策

对话回复改为逐字流式输出（思考过程与正文都流式显示），不再整段一次性返回。取代 [DIALOG-0002](DIALOG-0002-backend-orchestrated-reply.md) 中「不做流式」的部分。

## 实现要点

- 平台 AI 支持流式请求（SSE），把增量经推送通道推给前端；工具调用的参数分片到达，由平台拼装；
- 流式请求在中断时能让 DeepSeek 及时停止生成（非流式请求可能照样生成完并计费）。
