# DIALOG-0019 关掉联网搜索时工具定义照常带上：tool_choice = none，并补一句说明

- 状态：有效
- 日期：2026-10-28
- 决策者：作者
- 取代：[DIALOG-0009](DIALOG-0009-web-search-toggle.md) 中「关闭：不给这些工具」的部分
- 服务于：
  - 作者预期：[platform.md「平台 AI」](../../../../user-spec/platform.md)（对话过程中不改动工具定义）
  - 上游决策：[D-0078](../../../../user-spec/decisions/0078-tools-unchanged-within-conversation.md)

## 决策

- 搜索、抓取工具总是交给模型；联网搜索的使用说明也总是在系统提示词里；之前回复里的搜索过程总是放进历史；
- 联网搜索关掉时：请求设 `tool_choice: "none"`（不许调用），并在用户消息之后补一句「用户关闭了联网搜索功能，请不要调用 web_search、web_fetch，直接回答。」（作者要求补这一句）；
- 开关仍然可以在对话中途随时切换，只改变「这一次能不能调用」，不改变对话的前缀。

## 理由

原来关掉开关就不带工具定义、系统提示词里去掉搜索说明、历史里去掉搜索过程：对话中途一切换，缓存几乎全部失效，也让模型困惑（前面明明搜过）。

## 代价

- 关着的时候每次请求多带一两百 tokens 的工具定义与说明，几乎可以忽略；
- 补的那句说明不存进会话，下一次请求的历史里没有它：缓存只从这里开始不命中，影响很小。
