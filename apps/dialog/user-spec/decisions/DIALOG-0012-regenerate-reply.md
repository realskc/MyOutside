# DIALOG-0012 支持重新生成助手回复（在回复这一层分叉）

- 状态：有效
- 日期：2026-10-26
- 决策者：作者（要加入）；分叉位置由 agent 决定
- 服务于：
  - 作者预期：[对话 user spec「对话历史」](../README.md)（树形历史）

## 决策

- 可以让 AI 对同一个问题重新回答；
- 新的回答作为原回答的**兄弟节点**（父节点是同一条用户提问），并切换为当前选中；原回答保留，回答旁出现 `‹ i/k ›` 切换器。

取代 [DIALOG-0003](DIALOG-0003-edit-user-messages-only.md) 中「暂不支持重新生成助手回复」的部分；助手消息仍然不能编辑。

## 考虑过、没有采用

- 「编辑用户消息但不改内容」：会复制出内容完全一样的用户提问，树不干净。效果与本方案相近（作者最初就是这样理解的）。

## 什么时候应该重新考虑

随时可以。
