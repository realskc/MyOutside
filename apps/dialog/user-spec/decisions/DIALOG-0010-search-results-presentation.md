# DIALOG-0010 搜索结果的呈现：正文标注引用、下方列出来源（默认折叠）、搜索过程折叠

- 状态：有效
- 日期：2026-10-26
- 决策者：agent（作者表示随便）；「来源全部列出、默认折叠」由作者规定
- 服务于：
  - 作者预期：[对话 user spec「定位」](../README.md)（主力对话工具；接下来要加上搜索）

## 决策

- 回答正文中用 [1]、[2] 标注引用；
- 回答下方列出来源（标题与链接），点击用系统浏览器打开；
- 来源列出这次回复查过的**全部**网页（不只是正文引用了的），**默认折叠**，展开查看；
- 搜索过程（搜了什么、读了哪些网页）折叠显示，可以展开查看；
- 生成过程中实时显示进度（DIALOG-0008）。

## 理由

作者没有偏好。这是常见、清楚的做法：既能核对来源，又不让过程信息挤占正文。来源全部列出、默认折叠是作者规定的，作者没说原因（实际效果：一次回复常查十几个网页，展开的列表比正文还长）。

## 什么时候应该重新考虑

随时可以。
