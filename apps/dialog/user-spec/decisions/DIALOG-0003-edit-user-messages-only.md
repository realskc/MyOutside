# DIALOG-0003 只能编辑用户消息；暂不支持重新生成助手回复

- 状态：部分被取代（→ [DIALOG-0012](DIALOG-0012-regenerate-reply.md)）：「暂不支持重新生成助手回复」被取代
- 日期：2026-10-07
- 决策者：讨论
- 服务于：
  - 作者预期：[对话 user spec「对话历史」](../README.md)

## 决策

- 只有用户消息可以编辑：编辑 = 在原位置创建新分叉并自动重新生成回复；
- 助手消息不能编辑；「重新生成助手回复」后置（树形模型已支持：创建助手消息的兄弟节点即可）。

## 什么时候应该重新考虑

随时可以。
