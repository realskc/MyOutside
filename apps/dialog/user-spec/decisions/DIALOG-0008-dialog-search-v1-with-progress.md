# DIALOG-0008 对话搜索第一版就做进度推送

- 状态：有效（未实现）
- 日期：2026-10-21
- 决策者：讨论（作者同意）
- 服务于：
  - 作者预期：[对话 user spec「定位」](../README.md)（能作为主力对话工具）
  - 上游决策：[D-0051](../../../../user-spec/decisions/0051-event-centric-agent-runs.md)

## 决策

对话搜索的第一版同时实现内核推送通道：搜索过程中界面实时显示「正在搜索 xxx」「正在阅读 xxx」等步骤，而不是只显示「生成中」等待 10–60 秒。

## 理由

对话是主力工具，干等几十秒体验很差；推送通道迟早要做（逐字流式输出也复用它）。

## 什么时候应该重新考虑

随时可以。
