# DIALOG-0014 用量显示改为突出当前上下文长度

- 状态：有效（未实现）
- 日期：2026-10-26
- 决策者：讨论（作者同意）
- 服务于：
  - 作者预期：[对话 user spec「用量」](../README.md)（需要知道上下文长度）
- 取代：[DIALOG-0006](DIALOG-0006-usage-display.md)

## 决策

- 输入区旁直接显示**当前上下文长度**（例如「当前上下文：约 12,000 tokens」），取最近一次请求的输入 token 数（无回复时按估算）；
- 本会话累计用量与每条回复的明细放到悬停提示里。

## 理由

DIALOG-0006 中最醒目的数字是会话累计用量，与作者需要的「当前上下文长度」不是一回事。

## 什么时候应该重新考虑

随时可以。
