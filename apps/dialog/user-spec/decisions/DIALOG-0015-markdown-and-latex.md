# DIALOG-0015 对话回复渲染完整的 Markdown 与 LaTeX 公式

- 状态：有效
- 日期：2026-10-26
- 决策者：作者（要支持，前提是不麻烦）；库的选择由 agent 决定
- 服务于：
  - 作者预期：[对话 user spec「定位」](../README.md)（主力对话工具）

## 决策

- 回复中的 Markdown 完整渲染（表格、列表、代码块等）；
- LaTeX 公式渲染（行内 `$…$` 与独立 `$$…$$`）；
- 实现：使用成熟的渲染库（例如 Markdown 渲染器 + KaTeX），把库文件放进子应用前端目录，不引入构建步骤；仍然转义优先、链接只允许 http/https。

取代 [DIALOG-0007](DIALOG-0007-dialog-ui-details.md) 中「Markdown 极简渲染、零依赖」的部分。

## 理由

作者希望支持，前提是不麻烦；引入现成的库即可，工作量小。

## 什么时候应该重新考虑

- 引入的库带来明显的体积或安全问题时。
