# DIALOG-0005 发给 AI 的上下文按约 100 万 token 的预算截断

- 状态：有效
- 日期：2026-10-07
- 决策者：讨论
- 服务于：
  - 作者预期：[对话 user spec「对话历史」](../README.md)（存储不受限，所有消息永久保留）

## 决策

- 从当前路径末端往前累加，直到估算的 token 数接近 1,000,000；至少保留最近一条用户消息，保证序列从用户消息开始；
- 估算口径：中日韩字符约 1 token，其余字符约 4 个字符 1 token；
- 截断只影响发给 AI 的内容，不影响存储与界面。

## 什么时候应该重新考虑

随时可以（例如换成真正的 tokenizer，或按模型的实际上限自动适配）。
