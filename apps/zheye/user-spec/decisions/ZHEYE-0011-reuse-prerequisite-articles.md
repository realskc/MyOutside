# ZHEYE-0011 前置复用已有的文章：按「同一个概念、同一种含义」判断

- 状态：有效（未实现）
- 日期：2026-10-27
- 决策者：作者（复用、长期保存）；agent（怎么判断「同一个」，作者没有反对）
- 服务于：
  - 作者预期：[哲野 user spec「长期积累」](../README.md)（写过的文章长期保存，以后直接复用）
  - 上游决策：[ZHEYE-0001](ZHEYE-0001-zheye-explanation-units.md)（单元 → 文章一对一）、[ZHEYE-0002](ZHEYE-0002-zheye-prerequisites.md)（前置检查）

## 决策

- 一个重前置如果已经有对应的单元（文章已写好、正在写或在排队），就直接复用：新文章链接到它，不再新建，也不再询问；
- 「是不是同一个」不能只比文字（例如「熵」在热力学与信息论里是两个东西）：由 AI 判断是否同一个概念、同一种含义，是就复用，不是就新建；
- 单元与文章长期保存，不随某次学习结束而清理。

## 什么时候应该重新考虑

- 「同一个」的判断经常出错时；
- 同一个概念需要按不同角度、不同深度各写一篇时。
