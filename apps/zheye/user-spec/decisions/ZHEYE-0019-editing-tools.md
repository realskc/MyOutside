# ZHEYE-0019 写作用的编辑工具：读取、查找替换、整篇重写

- 状态：有效（试验台里已实现，ZHEYE-0021）
- 日期：2026-10-28
- 决策者：agent 提出，作者同意
- 服务于：

  - 相关决策：[ZHEYE-0018](ZHEYE-0018-writing-pipeline.md)（写作流程）

## 决策

- 写作的模型有三个编辑工具：
  - **读取**当前稿子；
  - **查找替换**：给出稿子里的一段原文和替换后的内容；原文必须恰好出现一次，找不到或出现多次就报错，模型看到报错后重试；
  - **整篇重写**：交出整篇新稿（推倒重来）；
- 稿子是哲野内部的草稿，不是磁盘上的文件；大纲、前置清单也可以作为草稿，用同样的工具修改；
- 每次编辑都是一次工具调用，试验台上能逐次看到改了哪里（ZHEYE-0020）。

## 理由

主流 agent 的编辑工具（2026-10 调研）：

- 精确查找替换：Claude Code 的 Edit、Anthropic 的 text editor 工具、OpenCode 的 edit；
- 补丁格式：Codex 的 `apply_patch`（`*** Begin Patch`、`@@` 锚点、`-` / `+` 行，不用行号），GPT 系列专门训练过，OpenCode 只对 GPT 模型启用；
- 整篇重写：各家的 write；
- 其他：Aider 在正文里写查找 / 替换块；Cursor 由主模型写草稿、小模型合并。

选查找替换而不选补丁：补丁按行改，而文章的一行往往是一整段，改一个词也要重写整段；DeepSeek 也没有专门训练过 Codex 的补丁格式。整篇重写满足「推倒重来」。

## 什么时候应该重新考虑

- 查找替换经常失败（例如模型复述原文不准）时；
- 换用专门训练过某种编辑格式的模型时。
