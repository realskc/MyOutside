# ZHEYE-0022 可以记录用户的特点；不做的是刻意迎合

- 状态：有效
- 日期：2026-11-05
- 决策者：作者
- 取代：[ZHEYE-0006](ZHEYE-0006-zheye-no-profiling.md) 中「不做口味档案」「不做任何画像」的部分（不做应用内反馈系统、不要求对原文高保真，这两部分保留）
- 服务于：
  - 作者预期：[哲野 user spec「愉悦」](../README.md)（不刻意迎合）

## 决策

- 哲野的目标是不刻意迎合（不投其所好）；这**不代表不能记录用户的特点**。
- 记什么、什么时候记、怎么用，以后再定。v1 的范围仍按 [ZHEYE-0008](ZHEYE-0008-zheye-v1-scope.md)。

## 理由

讨论 MyOutside 将来的统一记忆能力（记住用户的特点、经历、已有的知识，见 [统一能力「记忆数据统一」](../../../../user-spec/future/unified-capabilities.md)）时，agent 指出它和哲野 spec 里「不做性格或口味画像」有张力。作者澄清：哲野要的是不刻意迎合，不是不记录。早期的写法把这两件事混在了一起。

## 什么时候应该重新考虑

- 设计统一记忆，或哲野的知识库时，再定具体怎么记、怎么用。
