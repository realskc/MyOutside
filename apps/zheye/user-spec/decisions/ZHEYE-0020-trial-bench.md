## 决策

- 试验台是**哲野里的一个页面**，跑的就是哲野真正的流程代码；在 MyOutside 里运行，密钥不外露，花费计入「用量与花费」；不依赖哲野的正式界面和后台机制，可以先做；
- 提示词放在**仓库里的文件**中，用 git 记录修改；
- 第一版在试验台上**只读**显示流程图与各环节的提示词，提供「在编辑器里打开」；以后再考虑在界面里直接改；
- **每次试跑都存下**：所用提示词的版本、每一步的输入、思维链、工具调用与结果、每一版稿子、花费与用时；可以拿两次试跑对比。
