# ZHEYE-0012 记住作者对每个概念的了解情况，问过的不再问

- 状态：有效（未实现）
- 日期：2026-10-27
- 决策者：作者
- 服务于：
  - 作者预期：[哲野 user spec「长期积累」](../README.md)（问过一次「了解吗」，以后不再问）
  - 上游决策：[ZHEYE-0002](ZHEYE-0002-zheye-prerequisites.md)（只对重前置询问「是否了解」）

## 决策

- 哲野维护一份作者的长期记忆（知识库）：作者对前置选过「已了解」或「单独讲解」的，都记下来；选「正文带过」的不记（2026-10-27 作者细化，见 ZHEYE-0016）；
- 前置检查时，已经记录过的**直接按记录处理，不再询问**（判断「同一个」的方式同 ZHEYE-0011）；
- 了解程度会随时间变化的问题先不处理，做出一版之后再解决。

## 考虑过、没有采用

- 每次都重新问：会反复问同样的东西；
- 预先填好上次的回答、仍然显示出来让作者确认：作者选择直接跳过。

## 什么时候应该重新考虑

- 做出第一版之后（处理了解程度的变化、查看与修改记录）。
