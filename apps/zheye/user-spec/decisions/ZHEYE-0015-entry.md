# ZHEYE-0015 入口：投递材料与直接提出，讲成哪一类

- 状态：有效（未实现）
- 日期：2026-10-27
- 决策者：agent（投递材料后怎么处理、讲成哪一类由谁定：作者暂时没想好，先采纳 agent 的建议）；作者（断言可以用问题的形式提出）
- 服务于：
  - 作者预期：[哲野 user spec](../README.md)「目的」（投递了材料时至少讲到核心内容和总标题）、「讲解的对象与方法」

## 决策

**投递材料**（论文、新闻等）：

- 默认把这份材料当成一个**实体**，按实体的讲法写一篇；
- 另外由 AI 从材料里挑出值得单独讲的**概念和断言**，列成候选；作者勾选想学的才写，没勾的不写。

**直接提出**（「给我讲讲 X」）：

- AI 按作者的说法判断讲成哪一类，开始前显示出来，作者可以改。例：「Transformer 是什么」→ 实体；「为什么 Transformer 能 scaling」→ 断言；「讲讲通货膨胀」→ 概念；
- 两类都能讲的（例如 Transformer），默认挑一种，并告诉作者另一种也能讲，想看再点；不默认两种都写；
- **断言可以用问题的形式提出**（「为什么信息流会让人上瘾」「信息流会让人上瘾吗」）：AI 把它改写成断言再讲；如果这个说法本身有争议甚至是错的，按真实情况讲，不硬说它成立。

## 考虑过、没有采用

- 投递材料后只写一篇实体、不列候选：更简单，但一篇材料里常有值得单独讲透的点（新概念、反直觉的结论）。
- 两类都能讲的默认两种都写：费用翻倍，作者多半只想要其中一种。

## 什么时候应该重新考虑

- 随时可以（前两部分是作者暂时没想好时先采纳的建议）。
