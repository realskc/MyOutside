# ZHEYE-0002 哲野的前置检查：轻 / 重前置，只问重前置，全递归

- 状态：有效（未实现）
- 日期：2026-10-07
- 决策者：作者（认真思考后敲定）
- 服务于：
  - 作者预期：[哲野 user spec「目的」](../README.md)（低认知压力，同时真正学到东西）
  - 作者预期：[哲野 user spec「读者」](../README.md)

## 决策

- 生成前先精读目标，提出前置要素（词或句，尤其是领域前置知识），分为：
  - **轻前置**：正文里一两句就地解释；
  - **重前置**：需要独立成文；
- 只对重前置**批量**询问「是否了解」（一次一屏）；
- 回答的作用：
  - 了解 → 正文一句带过；
  - 不了解的重前置 → 先生成独立文章；
  - 不了解的轻前置 → 正文就地补；
- **全递归**：重前置文章自身也走同样的「前置检查 → 生成」流程。
