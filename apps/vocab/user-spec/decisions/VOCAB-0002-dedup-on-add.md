# VOCAB-0002 添加卡片时的查重：机械检查拼写 + AI 判断是否同义，不自动合并

- 状态：有效
- 日期：2026-10-01
- 决策者：讨论
- 服务于：
  - 作者预期：[学英语 user spec「卡片」](../README.md)

## 决策

1. 按 `term` 机械检查：不存在 → 直接新建；
2. 已存在 → 把该拼写已有卡片的「单词 + 意项 + 释义」交给平台 AI，判断新卡片是否与其中某张属于同一个本质意项；
3. 判定同义时**不自动合并**，告知用户，由用户选择：放弃 / 替换（覆盖展示字段，保留复习调度）/ 仍新增（界面里有，文档里原先只写了前两项）；
4. 没有配置 AI 密钥或 AI 调用失败时，回退为只做机械检查。

实现上拆成两步：`vocab.resolveCard`（判断）→ `vocab.addCard` / `vocab.updateCard`（提交），见 D-0008。

## 理由

作者对同义冲突的处理暂时没有考虑过，也一时半会儿用不到；只要求不至于崩溃。

## 什么时候应该重新考虑

随时可以。
