# VOCAB-0010 查重用低强度思考；添加卡片时做提交时校验

- 状态：有效
- 日期：2026-10-27
- 决策者：作者（低强度思考）、agent（提交时校验的做法，作者说「随便，搞一下」）
- 服务于：
  - 上游决策：[VOCAB-0002](VOCAB-0002-dedup-on-add.md)（添加时查重）、[D-0063](../../../../user-spec/decisions/0063-internal-apis-may-be-async-functions.md)（步骤之间的一致性由提交时校验保证）

## 决策

**查重用低强度思考**：`vocab.resolveCard` 判断「新卡片与已有卡片是否同一本质意项」时，平台 AI 的思考强度用 `low`（原来是默认的 `high`）。这一步只是比较两个意项，不需要深思，更快、更省。

**提交时校验**：
- `vocab.resolveCard` 返回判断时看到的这个拼写的全部卡片 id（`knownCardIds`）；
- `vocab.addCard` 可以带上 `knownCardIds`：提交时这个拼写若多出了别的卡片（判断之后别处又添加了），拒绝写入，错误码 `CONFLICT`；不带则不校验（导入脚本等）；
- 学英语的界面收到 `CONFLICT` 时自动重新判断一次。

## 理由

- 低强度思考：作者规定，作者没说原因（实际效果：查词添加时等待更短）；
- 提交时校验：「判断有没有重复」与「添加」是两步，中间可能被别的添加插入，导致出现重复卡片；按 D-0063，用提交时校验保证一致性，而不是长事务。

## 什么时候应该重新考虑

- 低强度思考判断不准、出现明显误判时；
- 其余随时可以。
