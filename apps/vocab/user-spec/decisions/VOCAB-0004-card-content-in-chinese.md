# VOCAB-0004 AI 生成的卡片内容一律用中文，例句保持英文

- 状态：有效
- 日期：2026-10-07
- 决策者：作者
- 服务于：
  - 作者预期：[学英语 user spec「卡片」](../README.md)（卡片全是英语容易头晕）

## 决策

查词时 AI 生成的卡片草稿（意项、释义等）一律用中文，与界面语言无关；例句保持英文。
