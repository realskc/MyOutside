# VOCAB-0011 音标统一使用美式 IPA（General American）

- 状态：有效
- 日期：2026-10-26
- 决策者：作者
- 服务于：
  - 作者预期：[学英语 user spec「卡片」](../README.md)（音标统一为美式）
  - 上游决策：[VOCAB-0007](VOCAB-0007-ai-lookup.md)（音标由 AI 产出）

## 决策

- 卡片音标统一使用 **General American（美式）IPA**，保留现有的斜杠写法；
- 一般单词只给一个最常用的美式读音；同一个词因词性导致读音不同（如 `defect` 名词 / 动词）时，可以保留多个读音并标注词性；
- 多词短语给整条短语的美式音标，不只给其中某个单词；
- AI 查词的 system prompt 与 `make_card` 工具 schema 都明确要求美式 IPA，并提示避免 `ɒ`、`əʊ`、`ɪə`、`eə`、`ʊə`、`zj` 等典型英式写法；
- 手工添加 / 编辑音标时，界面文案标明「美式」，但不做不可靠的自动方言转换；
- 存量卡片做一次性审计，逐张核对后更新 `phonetic`；保留旧值对照，不通过数据库 migration 修改用户数据；
- 旧 Vocabry 导入流程带入的音标需要检查，避免以后重新导入时又混入英式音标。

## 实施记录

- 2026-10-26：检查现有 42 张卡片，修正 7 张带英式写法的音标：`exude`、`impairment`、`anomaly`、`spurious`、`dissolve`、`choppy`、`onto`。

## 考虑过、没有采用

- **只改查词 prompt，不处理已有卡片**：已有 42 张卡片全部带音标，只改 prompt 会长期混用英式与美式；没有采用。
- **用固定符号映射自动把英式 IPA 转成美式**：英语拼写与音素的对应关系依赖具体单词（例如 `ɒ` 不能无条件换成 `ɑː`），自动转换会产生错音；没有采用。
- **新增 `phonetic_dialect` 字段，同时保存英式和美式**：当前只需要一种标准，增加字段会让数据与界面复杂化；没有采用。

## 代价

- AI 输出不能保证 100% 符合美式，仍需要人工检查和修正；
- 存量 42 张卡片需要逐张校对，短语和多音词需要特殊处理；
- 旧导入脚本没有音标方言信息，重新导入后可能需要再次清洗。

## 什么时候应该重新考虑

- 作者需要同时显示英式与美式音标，或需要真人发音音频时；
- 需要从外部词典自动同步音标时；
- 卡片的音标来源发生变化（例如不再由 AI 生成）。
