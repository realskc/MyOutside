# 网易云下载（netease）

Mac 上的简易网易云音乐客户端：搜歌、下载到网易云音乐的文件夹（默认 `~/Music/网易云音乐`），旁边存歌词。只给作者自己用。

- 作者预期：[`user-spec/README.md`](user-spec/README.md)
- 技术文档：[`docs/README.md`](docs/README.md)
- 决策：[`user-spec/decisions/README.md`](user-spec/decisions/README.md)

## 使用

1. 安装官方网易云音乐（macOS），并登录。本应用不负责登录，只读官方客户端的登录状态。
2. 在 MyOutside 里打开「网易云下载」，搜歌，点「下载」。默认按账号能下的最高音质；也可以在「音质」里选低一点的。
3. 顶栏可以改下载文件夹。
