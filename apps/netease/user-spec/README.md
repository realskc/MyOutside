# 网易云下载（netease）user spec

> 应用 id：`netease`；中文名：网易云下载（作者，2026-11-11）。这是作者的预期；技术文档见 [`../docs/README.md`](../docs/README.md)；决策见 [`decisions/`](decisions/README.md)。

一句话：**Mac 上的简易网易云音乐客户端：搜歌、下载。**以后也许支持 Windows（作者，2026-11-11）。

## 定位

- **只是一个小工具**，不是纯蓝那样自己设计的正经子应用；取个死板无聊的名字就行（作者，2026-11-11）。
- **只做搜索和下载**（作者，2026-11-11）。不做在线播放、歌单同步、歌词显示。
- **现阶段只给作者自己用**，以后要分发时再讨论（作者，2026-11-11）。代码照常放进公开仓库（作者：它只是 MyOutside 的一小部分，仓库现在也没人关注）。原因：它用的是网易云的非官方接口和作者自己账号的登录状态，自己用没问题；作为产品发给别人，有法律和平台规则上的风险（[product.md「双重使命」](../../../user-spec/product.md) 说的需求层面的冲突，作者决定先按个人用处理）。

## 登录与凭据

- **不负责登录**：用本机官方网易云客户端已有的登录状态，凭据从本地抓（作者）。作者认为所有 Mac 上的位置应该是同一个。
  - agent 注：这台 Mac 上在 `~/Library/HTTPStorages/com.netease.163music.binarycookies`（官网下载的客户端，3.1.13）；App Store 版如果有沙盒，可能在 `~/Library/Containers/…` 下（推断，没验证）。
- 凭据不能泄露（[AGENTS.md「红线」](../../../AGENTS.md)第 3 条）：不出现在界面、日志、数据库、命令行里。

## 下载

- **付费歌、高音质都可以下**；下下来是加密的 `.ncm` 时，可以用 ncmdump 转（作者，2026-11-11）。作者：只是本地自己用、不分发；作者平时自己听歌也会下付费歌、用 ncmdump。
- **默认下载到网易云音乐的文件夹**（官方客户端的下载文件夹；这台 Mac 上是 `~/Music/网易云音乐/`）（作者）；设置里留一个「改文件夹」的选项，不改就一直用默认（agent 提议，作者同意）。
- **文件和官方客户端一样命名**（`歌手 - 歌名.扩展名`），旁边照样存同名的 `.lrc` 歌词文件，留给纯蓝以后显示歌词用（agent 提议，作者同意）。
- **不在这一层自动导入纯蓝**；最多向纯蓝开放「下载」和「访问下载的音乐文件夹」（作者）。现在两个都已公开（「下载」是公开的普通异步函数，见 [D-0086](../../../user-spec/decisions/0086-public-async-functions.md)）；搜索仍是内部的。
- **硬性限制，防止高频连续下载被官方封控**（作者，2026-11-11）：
  - 相邻两次下载之间，间隔 10–20 秒的随机时间；实现方式随意（例如在应用内部排队）；
  - 每天最多下载 50 首。

## 名字

作者第一反应是就叫「网易云音乐」（它本来就是一个客户端，和本地的官方网易云音乐一样），但担心重名侵权。仓库是公开的，直接叫「网易云音乐」像在冒充官方；改叫说明用途的「网易云下载」（agent 提议，作者同意）。
