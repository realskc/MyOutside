# 网易云客户端（名字未定）

> 目录名暂用 `netease`，起好名字后改。这是作者的预期，还没有开始设计和实现。

一句话：**Mac 上的简易网易云音乐客户端：搜歌、下载。**以后也许支持 Windows（作者，2026-11-11）。

## 定位

- **只做搜索和下载**（作者，2026-11-11）。不做在线播放、歌单同步、歌词显示。
- **现阶段只给作者自己用**，以后要分发时再讨论（作者，2026-11-11）。原因：它用的是网易云的非官方接口和作者自己账号的登录状态，自己用没问题；作为产品发给别人，有法律和平台规则上的风险（[product.md「双重使命」](../../../user-spec/product.md) 说的需求层面的冲突，作者决定先按个人用处理）。

## 登录与凭据

- **不负责登录**：用本机官方网易云客户端已有的登录状态，凭据从本地抓（作者）。作者认为所有 Mac 上的位置应该是同一个。
  - agent 注：这台 Mac 上在 `~/Library/HTTPStorages/com.netease.163music.binarycookies`（官网下载的客户端，3.1.13）；App Store 版如果有沙盒，可能在 `~/Library/Containers/…` 下（推断，没验证）。
- 凭据不能泄露（[AGENTS.md「红线」](../../../AGENTS.md)第 3 条）：不出现在界面、日志、数据库、命令行里。

## 下载

- **付费歌、高音质都可以下**；下下来是加密的 `.ncm` 时，可以用 ncmdump 转（作者，2026-11-11）。作者：只是本地自己用、不分发；作者平时自己听歌也会下付费歌、用 ncmdump。
  - 起源的 CLI 只下免费歌、标准音质，是因为作者只让 Codex 做了个 demo；Codex 文档里写的使用边界不决定产品怎么用（作者）。
- **默认下载到网易云音乐的文件夹**（官方客户端的下载文件夹；这台 Mac 上是 `~/Music/网易云音乐/`）（作者）。能不能另外指定，作者还没想好。
- **不在这一层自动导入纯蓝**；最多向纯蓝开放「下载」和「访问下载的音乐文件夹」（作者）。

## 起源

作者让 Codex 写的 CLI demo：`~/Documents/Codex/2026-11-10/new-chat/outputs/netease_download.py`，同目录有两份研究记录（下载、本地认证）。2026-11-10 agent 用它在这台 Mac 上搜索、下载成功。
